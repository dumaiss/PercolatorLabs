## Component Details

### 1. Core Emulator — `vrEmuTms9918.c/.h`

| Property | Value |
|----------|-------|
| Language | C99 |
| Lines | 767 (C) + 222 (H) = 989 |
| Builds as | `libvrEmuTms9918.so` (shared library) |
| Dependencies | `stdlib.h`, `memory.h`, `math.h`, `string.h` (all standard C) |
| Key struct | `vrEmuTMS9918_s` — opaque, holds registers, status, VRAM, address state, mode |

**Internal subsystems**:
- **Register/Address protocol** (`WriteAddr`, `WriteData`, `ReadStatus`, `ReadData`)
- **Mode detection** (`tmsMode`) — determines active display mode from register bits
- **Address resolution helpers**: `tmsNameTableAddr`, `tmsColorTableAddr`, `tmsPatternTableAddr`, `tmsSpriteAttrTableAddr`, `tmsSpritePatternTableAddr`
- **Color resolution**: `tmsMainBgColor`, `tmsMainFgColor`, `tmsFgColor`, `tmsBgColor`
- **Sprite subsystem** (`vrEmuTms9918OutputSprites`): 32 sprites, magnification, 16×16 mode, early clock, collision, 5th-sprite, per-scanline limit of 4
- **Mode renderers**: `GraphicsIScanLine`, `GraphicsIIScanLine`, `TextScanLine`, `MulticolorScanLine`
- **Scanline dispatch** (`vrEmuTms9918ScanLine`): checks display enabled, dispatches by mode, sets VSYNC interrupt

### 2. Utility Library — `vrEmuTms9918Util.c/.h`

| Property | Value |
|----------|-------|
| Language | C99 |
| Lines | 110 (C) + 195 (H) = 305 |
| Builds as | `libvrEmuTms9918Util.so` (links against `vrEmuTms9918`) |
| Key export | `vrEmuTms9918Palette[]` — 16-entry RGBA color table |

**Key helpers**:
- `WriteRegisterValue(reg, value)` — atomic register write
- `SetAddressRead(addr)` / `SetAddressWrite(addr)` — VRAM pointer setup
- `WriteBytes`, `WriteByteRpt`, `WriteString`, `WriteStringOffset` — bulk VRAM writes
- `SetNameTableAddr`, `SetColorTableAddr`, `SetPatternTableAddr`, `SetSpriteAttrTableAddr`, `SetSpritePattTableAddr` — register-based table address setup
- `FgBgColor`, `SetFgBgColor` — color composition
- `InitialiseGfxI`, `InitialiseGfxII` — full mode initialization with VRAM clear
- `clearTmsRam` — internal: clears VRAM and initializes sprite attributes

### 3. Python Bindings — `pybindings/tms9918.cpp`

| Property | Value |
|----------|-------|
| Language | C++11 + pybind11 |
| Lines | 74 |
| Builds as | Python extension module `tms9918.<so>` |
| Linking | Static link against `vrEmuTms9918` + `vrEmuTms9918Util` |
| Compile flag | `-D VR_TMS9918_EMU_STATIC` (static linking mode) |

**Exposed class**: `Tms9918`
- Constructor: `vrEmuTms9918New()`
- Destructor: `vrEmuTms9918Destroy()`
- `setReg(reg, val)` → `vrEmuTms9918WriteRegValue()`
- `setRegs(list)` → batch register write
- `setVram(addr, data)` → `vrEmuTms9918SetAddressWrite()` + `vrEmuTms9918WriteBytes()`
- `getScreen()` → iterates all 192 scanlines, renders to RGB framebuffer

### 4. Test Harness — `pybindings/test.py`

| Property | Value |
|----------|-------|
| Language | Python 3 |
| Lines | 16 |
| Dependencies | `PIL` (Pillow), `tms9918` (the built extension) |

**Workflow**:
1. Load `image.bin` (16392 bytes = 16KB VRAM + 8 registers)
2. Write registers via `setRegs()`
3. Write VRAM via `setVram()`
4. Render via `getScreen()` → RGB byte array
5. Display via `PIL.Image.frombytes()` + `.show()`

### 5. Test Data — `pybindings/image.bin`

| Property | Value |
|----------|-------|
| Size | 16,392 bytes |
| Format | 16,384 bytes VRAM + 8 bytes register values |
| Layout | offsets 0x0000–0x3FFF: VRAM; offsets 0x4000–0x4007: R0–R7 |
