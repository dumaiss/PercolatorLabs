# Testing

## Build

```bash
cd build
cmake ..
make
```

GCC and Clang supported. `-Wall -Wextra -Wpedantic` on non-MSVC. C11 with no
extensions.

## Automated Tests

### Proxy Protocol Tests
```bash
./virtual-vdp --test
```
6 tests (source: `src/test_protocol.c`):
1. `test_round_trip` — 6 boundary payload lengths (0..1024)
2. `test_parser_resync` — invalid declared length → resync
3. `test_back_to_back` — consecutive valid frames
4. `test_type_only` — zero-payload PING packet
5. `test_stream_decode` — opcode parsing, unknown opcode, NOP, presentation
6. `test_upload` — begin/data/end lifecycle, duplicate, rejection

### Emulator Tests
Built as part of the vDrip9958 backend:
- `test_core` — register, port, display metadata
- `test_render` — representative rendering smoke tests
- `test_commands` — command engine progression

```bash
ctest --test-dir build
# or run individually:
./build/bin/test_core
./build/bin/test_render
./build/bin/test_commands
```

## Replay Fixtures

Located in `tests/packets/`. TMS9918 fixtures (`*.bin`) and V9958 fixtures
(`v9958_*.bin`). Generated by Python scripts in `tests/generators/`.

```bash
# Regenerate all TMS fixtures
cd tests/generators && python3 generate_all.py

# Regenerate V9958 fixtures
python3 gen_v9958_suite.py
python3 gen_v9958_g6_bars.py     # manual
python3 gen_v9958_text1_hello.py  # manual
```

Verify a fixture:
```bash
python3 tools/serial_replay.py --dry-run tests/packets/v9958_g6_interlace.bin
```
